# Changelog / История изменений

## AI Unlock 4.5

### English

- Hardened the passive hosts update path with source, size, syntax and AI-domain validation.
- Kept updates and diagnostics behind the Magisk action button; no background service or DNS mutation.
- Added atomic replacement, backups, update locking and conflict checks for other hosts modules.
- Published the Magisk update feed through GitHub `update.json`.

### Русский

- Усилен пассивный путь обновления hosts: проверяются источник, размер, синтаксис и AI-домены.
- Обновление и диагностика выполняются только кнопкой действия Magisk; фоновой службы и изменения DNS нет.
- Добавлены атомарная замена, резервные копии, блокировка повторного запуска и проверка конфликтующих hosts-модулей.
- Лента обновлений Magisk опубликована через GitHub `update.json`.
